# Blobless partial clones and per-Review worktrees (not shallow clones)

Remote repositories are cached as blobless partial clones (`git clone --filter=blob:none`), with separate git worktrees for each Review's Base and Head and for each Revision. Local repositories aren't cloned; worktrees and private Snapshot refs are added to the user's own repo. We rejected shallow clones (`--depth`), even though they look like the obvious "fetch just enough" choice: they drop the history needed to compute the merge-base that defines a Pull Request's true Base, to Interdiff across force-pushed Iterations, and to give agents `git log` / `git blame`. A blobless clone keeps the full commit graph and fetches file contents only when they're needed, so its speed and disk use stay close to a shallow clone's.
