ExplanationFast tier · cached
RefundService.refundOrder
Before

Refunded the whole order total in one gateway call, then wrote an audit entry with the operator's id.

After

Refunds amount, defaulting to the remaining balance, and rejects anything larger. Shipping is included only on the final refund. Emits refund.issued instead of writing the audit log.

What changed
  • Partial refunds, as the Intent asks.
  • New shipping rule, missing from the PR description.
  • No longer calls auditLog(). The event drops operator.
Watch out

Two concurrent partial refunds can read the same balance.count and send the same idempotency key. The gateway drops the second one.
