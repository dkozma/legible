RefundService.calculateRefundable

new method Step 3
Before

Omitted. This method is new in this Change Set.

After

Returns the order's refundable balance: the amount paid minus every refund already issued, plus how many refunds exist. Callers treat remaining as the cap for the next refund.

What changed
  • Makes partial refunds possible, as the Intent asks.
  • Called by refundOrder and postRefund. Calls RefundRepository.listForOrder, one query each time.
Watch out
  1. 1Rounds each refund to cents before summing. Three $33.33 refunds on a $100 order leave $0.01 that can never be refunded.
  2. 2Counts pending refunds as issued. A failed gateway call blocks that amount until it's reconciled.
